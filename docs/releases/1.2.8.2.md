# PrintOps 1.2.8.2

Security patch following 1.2.8.1; resolves Dependabot alerts 123–126 (#250).

- The optional locally built native OrcaSlicer sidecar updates body-parser to
  2.4.0, Multer to 2.5.0 and qs to 6.17.1. The HTTP parser fix prevents process
  crashes from compressed requests with trailing bytes. The pinned wrapper
  source and OrcaSlicer engine remain unchanged.
- Development environments update virtualenv to 21.14.13 against delayed Bash
  prompt injection. Production Python dependencies are unchanged.
- Includes the previously merged Telegram upstream comparison and issue
  selection from #244/#248. See CHANGELOG.md for the release scope.

Existing native-sidecar users must rebuild their local image from this source
to receive the Node dependency fixes; updating only the main PrintOps container
does not replace a running sidecar. Follow the existing
[native sidecar build instructions](../../slicer-api/README.md#native-orcaslicer-on-arm64-or-amd64-linux).
The default third-party GHCR sidecar images are independently maintained and
are not fixed by this release.

Back up application data and configuration before updating. Publication does
not update a running installation. Windows installers remain unsigned with
checksums and artifact attestations. Existing configured native-updater tag
signature requirements remain effective; signed release tags are optional.
