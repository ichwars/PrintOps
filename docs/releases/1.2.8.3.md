# PrintOps 1.2.8.3

This patch integrates the reviewed November 2026 Bambuddy changes and the
security fixes in [PR #257](https://github.com/ichwars/PrintOps/pull/257) and
[PR #258](https://github.com/ichwars/PrintOps/pull/258).

## Highlights

- More reliable AMS and spool mapping, drying and dispatch, with queued jobs
  retaining the printer, plate and filament choices relevant to each run.
- Per-run archive history and media, duplicate archive merging, improved
  camera recovery, and background timelapse editing.
- More consistent stock, filament-use and cost records, reusable product and
  colour profiles, and printable label sheets.
- Tighter authorization for printers, archives and live feeds, safer backup
  restores, credential redaction and PostgreSQL migration repairs.

The [changelog](../../CHANGELOG.md) lists the complete set of changes.
The [feature guide](../upstream-features-guide.md) covers user-facing changes.

## Security and upgrades

- The runtime and development locks use `pyasn1` 0.6.5
  (CVE-2026-119194 through CVE-2026-119197). The affected `minimatch` and
  native-slicer `glob` dependencies use 11.0.1 and 14.0.2 respectively
  (CVE-2026-118764 and CVE-2026-118773).
- Docker application and test containers use unprivileged users. Update custom
  Compose configurations to include the separate `printops-init` service,
  retaining existing mounts and matching `PUID`/`PGID` to bind-mount ownership.
  See [Docker runtime security](../docker-runtime-security.md) for migration
  and custom CA instructions.
- Rebuild a locally built native OrcaSlicer sidecar to receive its dependency
  fixes. Follow the [native sidecar build instructions](../../slicer-api/README.md#native-orcaslicer-on-arm64-or-amd64-linux).
  Third-party slicer images are maintained separately.
- Back up data and configuration before upgrading. Users with existing
  browser sessions may need to sign in again after the upgrade.

Windows installers are unsigned and include SHA-256 checksums and GitHub
attestations. Container builds for AMD64 and ARM64 include SBOM, provenance
and a digest attestation. See [release integrity](../release-security.md).
