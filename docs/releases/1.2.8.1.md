# PrintOps 1.2.8.1

Security patch following 1.2.8.0. See CHANGELOG.md for the complete released scope.

- Correct DOMPurify and Brotli vulnerabilities in the frontend, Python runtime,
  container and the separately bundled Windows PDF renderer.
- Update affected Python/frontend build and audit dependencies. Include the
  previously merged aiohttp and optional native-slicer Vitest security fixes.
- Preserve application workflows, PDF-renderer versions and Windows dependency
  markers. Rebuild the tracked frontend bundle for native installations.
- Weekly local security maintenance runs Mondays at 09:00 Europe/Berlin. It
  repairs confirmed findings through verified PRs and automatically publishes
  tested security patches for shipped software. Development-only fixes need no
  release. Details: [release integrity](../release-security.md).

Back up application data and configuration before installing. Publication does
not update a running installation. Existing configured native-updater tag
signature checks remain effective. Signed tags are optional; Windows installers
are explicitly unsigned and include checksums and artifact attestations.
